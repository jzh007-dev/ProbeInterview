## 交付单元（每个 = 一个提交 = 一次交接 = 一次会话）

**做完一个就提交、停下等 review，不要连做下一个。** 划分标准：人能在一个坐姿里审完
（约 ≤500 行 diff）。连做多个单元会让 review 积压到无法开始，而且后面的单元会替前面的
背上下文——这是实测里最贵的一项开销。
